### ⚡ Engineering Impact

**🔄 Workflow Automation — From Hours to Minutes**

- Engineered a **self-service report-mapping and scheduling workflow** using Angular and Spring Boot.
- Replaced a manual process requiring **four configuration files** with database-driven mapping configuration.
- Enabled Operations teams to configure queries, selected columns, filters, email recipients, and execution schedules through a UI.
- Reduced mapping setup time from **1–2 hours to 1–2 minutes (~97–99%)**.
- The workflow supports **100+ active mappings**.

**🚀 MarketWatch Performance Optimization**

- Investigated request-processing bottlenecks in a production MarketWatch service supporting auction visibility.
- Reduced repeated Redis reads, deserialization, and shared computations in the request path.
- Introduced precomputed data snapshots to improve request-processing efficiency and reduce unnecessary work.

**⚙️ Backend & Trading Systems**

- Contributed to **continuous matching-engine and order-routing workflows** for auction and trading applications.
- Developed and integrated REST APIs, backend services, and Redis-backed functionality.
- Worked on SQL diagnostics, data synchronization, scheduler investigations, and application troubleshooting.
- Supported UAT and production releases across multiple enterprise platforms.
